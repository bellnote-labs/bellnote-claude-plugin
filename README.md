# Bellnote plugin for Claude Code

Connects Claude Code to Bellnote's MCP server (`https://api.bellnote.app/mcp`) and adds a skill for using it well.
Install it in Claude Code:

```
/plugin marketplace add balajivenki/bellnote-claude-plugin
/plugin install bellnote@bellnote
```

Then run `/mcp`, pick **bellnote** and choose **Authenticate** to sign in with your Bellnote email code.

Set up Bellnote in the app first. More about connecting AI assistants, what the tools do, and how your family's data stays safe: https://bellnote.app/ai/

This repository is a copy of `integrations/claude-plugin` in Bellnote's main (private) repository; changes are made there.
